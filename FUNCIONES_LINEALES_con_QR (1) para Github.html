📘 ¡Recuerda las fórmulas!

🔹 Función lineal:
f(x) = m·x + b   (y = mx + b)
🔹 Pendiente:
m = y₂ − y₁x₂ − x₁
🔹 Ordenada: b = y − m·x
(es el valor de y cuando x = 0)
🔹 m > 0 ↗ creciente
🔹 m < 0 ↘ decreciente
🔹 m = 0 ➡ constante
